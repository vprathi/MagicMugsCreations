# Magic Mugs Creations

Product customizer for the Coffee and Paper co. multi-photo family mug, modeled on Zazzle's customizer.

## What's in here

- `index.html` — the whole customizer in one file. Open it in a browser, no build step and no server needed.
- `.gitignore` — ignores OS files and `node_modules/`.
- `.nojekyll` — tells GitHub Pages to serve the files as-is.

## The mug

- Classic Mug, 11 oz, Burgundy theme
- $14.33 sale / $16.85 list, quantity 1 by default
- 5 replaceable tilted photo slots with white borders
- One text field, defaulting to "the / anderson / family"
- Design area 8.5 in × 3.6 in, with a Safe area guide
- 10 themes, style/size upcharges, PNG export
- Design → Options → Review flow

## How to use it

1. Open `index.html` in a browser, or visit the GitHub Pages site once it's enabled.
2. Click a photo slot to replace it with your own photo.
3. Edit the family name text.
4. Pick a theme, style, and size, then export the design as a PNG.

The sample photos in the slots are placeholders — replace all five with your own photos before using a design.

## Live site

To turn it on, go to **Settings → Pages** and set the source to **Deploy from a branch**, branch `main`, folder `/ (root)`. The live site will then be at `https://vprathi.github.io/MagicMugsCreations/`.
